# Поток

Календарь, который можно настроить под себя: события, связанные записи, собственные шаблоны карточек и переносы с сохранением истории.

Открытый репозиторий содержит интерфейс, логику и исходники приложения Tauri. По умолчанию данные сохраняются на устройстве; подключение своего Firebase необязательно. Настройки и публикация нашего сайта находятся в отдельном закрытом репозитории.

## Разработка в браузере

Нужны Node.js 24.12+ и npm.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:4173/. Локальное приложение открывается сразу, без аккаунта. Браузер остаётся основным способом разработки интерфейса.

## Приложение Tauri

```sh
npm run desktop:dev
npm run desktop:build
```

Дополнительно нужны Rust и системные инструменты: [официальные требования Tauri](https://v2.tauri.app/start/prerequisites/). В репозитории лежит начальный desktop-каркас; установщики пока не публикуются. Системный Google OAuth и переход с текущего локального хранения на SQLite — отдельные следующие этапы, они не входят в разделение репозиториев.

## Возможности

- Неделя по времени, доска, две недели и месяц.
- Быстрое перемещение карточки и удержание с календарём на 14 дней.
- Повторы, разовый перенос, очередь ожидания и история.
- Связанные записи и настраиваемые поля шаблонов.
- Именованные ссылки, PNG-фоны, карта мест событий.
- Напоминания о конкретных переносах.

## Своё облако

Подключение настраивается в «Настройки → Своё облако» или через локальный `.env.local`. В исходниках нет встроенного подключения к чужому проекту.

[Инструкция подключения Firebase](docs/architecture/sync/SELF_HOSTING.md). Облачное расписание пока требует сети для записи; локальный режим работает независимо от облака.

## Проверки

```sh
npm test
npm run test:ui
npm run build
```

Для проверки правил Firestore нужны Java 21 и команда `npm run test:rules`. Проверки используют демонстрационный проект, не рабочую базу.

## Устройство проекта

- `src/App.jsx` — рабочее пространство и общий интерфейс.
- `src/components/` — календарь, карточки, редакторы и настройки.
- `src/lib/` — модель событий, хранение и подключение облака.
- `src/hooks/` — состояние пространства и жесты.
- `src-tauri/` — системная оболочка приложения.
- `examples/firebase/` — пример правил для своего Firebase.
- `tests/` — проверки поведения и модели.
