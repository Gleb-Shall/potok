# Уроки — личное расписание

Локальное приложение на Preact + Vite. Уроки с учениками, университетские пары, личные события и собственные типы карточек.

## Запуск

Нужны Node.js 22.12+ и npm.

```sh
npm install
npm start
```

Открыть http://127.0.0.1:4173/.

```sh
npm run build
```

Готовая сборка находится в `dist/`. Настройка Firebase Hosting указывает на эту папку, но публикация и CI/CD ещё не выполняются.

## Что реализовано

- Отдельная база учеников; события могут существовать без связи с учеником.
- Готовые типы: урок, пара, личное мероприятие.
- Редактор названия, даты, времени, длительности, цвета, заметок и занятости.
- Конструктор типов: текст, длинный текст, число, дата, список, флажок. Настраиваются порядок, обязательность и показ на карточке.
- Скрытие использованных полей и архивирование типов без удаления существующих значений.
- Повтор каждые 1–12 недель с необязательной датой окончания.
- Изменение одного экземпляра либо выбранного и последующих событий.
- Переносы с историей, отметкой старого времени и списком событий без новой даты.
- Проверка пересечений для событий, занимающих время.
- Отмена последнего изменения, сохранение в браузере, экспорт и восстановление JSON-копии.
- Раздельное хранение демо и личного расписания; миграция старого формата с сохранением исходной копии.

## Структура

```text
index.html             Точка входа
src/
  main.jsx             Запуск Preact и обработка ошибок
  App.jsx              Разделы приложения и управление состоянием
  components/          Карточки, редакторы событий, учеников и типов
  lib/events.js        Общая логика событий и повторений
  lib/storage.js       Сохранение, миграция, резервные копии
  lib/domain.js        Независимые операции с датами и временем
  lib/legacy-*.js      Совместимость с предыдущей версией
  lib/firebase-client.js  Заготовка подключения Firebase
  styles.css           Основное оформление
  editor.css           Оформление редакторов и конструктора
public/icon.svg        Иконка приложения
tests/                 Ранее написанные проверки логики
```

## Данные и подключение облака

Рабочие данные хранятся в localStorage этого браузера. Текущая схема: `version`, `students`, `types`, `series`, `events`, `revision`. При первом запуске новой версии прежние `lessons` преобразуются в общие события, а ключи хранения v1 сохраняются как исходная копия.

Firebase-вход, синхронизация, собственное HTTP API и CI/CD пока не подключены к интерфейсу. `firestore.rules` относится к предыдущей схеме и перед подключением облака требует обновления и проверки. Клиентская конфигурация Firebase предназначена для браузера; приватные ключи и личные данные в репозиторий не добавляются.

## Проверка текущей версии

После перехода проверены только сборка и открытие страницы. Новые функции не проходили полный автоматический или ручной прогон — пользователь проверяет их самостоятельно. Существующий `npm test` относится к предыдущей логике и не заменяет проверку нового редактора.

Рекомендуемый порядок: создать пару без ученика; свой тип и его поля; разовое и повторяющееся событие; перенос одного экземпляра; изменение дальнейшего расписания; ожидание новой даты; перезагрузка; резервная копия.
