## Measurements

Measured on the user's MacBookAir10,1, arm64, macOS 27.0.1. Both application builds came from `72a9b6f5ec54869c3c70ab513196cfcffe7b8120`; [successful macOS build run](https://github.com/Gleb-Shall/potok/actions/runs/42322804322). Flutter 3.47.9, release AOT universal binary running arm64; current Preact calendar in a release arm64 Tauri bundle.

| Workload | Implementation | Median MiB | Sample min–max MiB | Two launch medians MiB |
| --- | --- | ---: | ---: | ---: |
| Empty week | Tauri | 155.5 | 154.2–205.7 | 173.7 / 154.2 |
| Empty week | Flutter | 107.7 | 98.2–170.7 | 135.0 / 98.2 |
| 40 events | Tauri | 207.9 | 203.3–214.6 | 211.7 / 203.7 |
| 40 events | Flutter | 99.1 | 97.8–130.0 | 97.8 / 99.1 |

For the 40-event workload, Flutter's median footprint was **52.4% lower**, or **2.10× smaller**. These are measurements of a smaller calendar prototype, not a guarantee for an equivalent complete Flutter product.

Method: two fresh launches per implementation/workload, alternating order; each launch warmed for 20 seconds followed by ten samples spaced by two seconds. Each table median combines 20 samples. 1 MiB = 1,048,576 bytes. Sum `ri_phys_footprint` for all application resource-coalition members, including WebKit content/networking/GPU, Metal compiler and app-attributed XPC services. RSS and the Tauri host process alone are not used for the headline numbers. Raw diagnostic samples stay local in `memory.json` (ignored by git); only synthetic calendar data was used.

Limits: same 40 events, week, 1280×800 content size, light theme, 24-hour grid, 76px/hour; no cloud, maps, login, landing animations or developer tools. The renderers and complete feature sets differ. Tauri retains its automatic scroll near the current time; Flutter initially scrolls to 08:00. This is not a renderer-only microbenchmark. First-launch graphics compilation/cache activity explains part of the range. Shared system services such as WindowServer are not apportioned. No battery, CPU/FPS, leak or long-session claims are made.
