Первая устанавливаемая версия Потока для Windows и macOS.

## Загрузка

- **Windows 10/11, x64:** файл `Potok_*_x64-setup.exe`.
- **Mac с Apple Silicon (M1 и новее), macOS 12+:** файл `Potok_*_aarch64.dmg`.
- **Mac с Intel, macOS 12+:** файл `Potok_*_x64.dmg`.

На Mac открой DMG и перетащи Potok в «Программы». На Windows запусти установщик: установка производится для текущего пользователя. Если WebView2 отсутствует, установщик предложит загрузить его; для этого нужна сеть.

## Что работает

- Календарь по времени и доска, день/неделя/месяц.
- Перетаскивание, выбор даты удержанием, разовые переносы и очередь ожидания.
- Связанные записи, свои шаблоны, ссылки, PNG-фоны и карты.
- История, подтверждение проведения, напоминания внутри приложения.
- Светлое и тёмное оформление.

## Данные и облако

Это **открытая локальная версия**. В ней нет конфигурации Firebase владельца проекта и готовой синхронизации с нашим сайтом. Расписание сохраняется в профиле приложения на устройстве. Данные браузерного сайта автоматически не переносятся; для переноса используй экспорт/импорт JSON в настройках. Рекомендуется сохранять резервную копию перед обновлением.

Подключение собственного облака остаётся экспериментальным: системный Google OAuth для настольной оболочки пока не реализован. Для обычной работы аккаунт не требуется. SQLite, фоновая доставка напоминаний при закрытом приложении и автоматическое обновление пока не подключены.

## Статус сборок

Предварительная версия для тестирования. Сертификаты доверенного издателя Windows и Apple Developer/notarization пока не настроены: ОС может предупредить о неизвестном разработчике или заблокировать первый запуск. Подпись macOS — локальная ad-hoc, она не заменяет Apple notarization.
