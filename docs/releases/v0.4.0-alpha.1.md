## Что нового

- **Шаблоны.** Редактируй поля событий и записей в одном интерфейсе, меняй порядок перетаскиванием, связывай поля с записью и настраивай вид карточки с живым предпросмотром.
- **Архив.** Шаблон можно скрыть из активных и позже вернуть. При удалении шаблона события и серии переходят в журнал. Из журнала их можно удалить окончательно по одному или очистить весь раздел.
- **Журнал и статистика.** Подтверждай проведённые события, разбирай очередь переносов и считай часы или суммы по выбранным полям за нужный период.
- **Календарь.** Перетаскивай события по времени, меняй длительность за края карточки и открывай детали двойным кликом.
- **Руководство.** Встроенные интерактивные примеры показывают, как работают переносы, шаблоны, связанные записи и статистика.

## Установка

- Windows x64 — `Potok_*_x64-setup.exe`.
- macOS Apple Silicon — `Potok_*_aarch64.dmg`.
- macOS Intel — `Potok_*_x64.dmg`.

Публичная сборка хранит расписание локально. Для переноса данных между установками используй экспорт и импорт JSON в настройках. Сборки предварительные. Для macOS используется ad-hoc подпись без нотариализации, а установщик Windows пока без сертификата издателя.
