### Format: что удалось установить по коду

Публичные файлы и их контрольные суммы записаны в [format-source-index.json](format-source-index.json). Технический разбор подтверждает **GSAP ScrollTrigger** и **Lenis**. Прогресс сцены задаётся линейно прокруткой; внутри него рассчитываются отдельные фазы. В сцене часов синхронно меняются угол стрелки, активная метка, позиция и масштабы фигур. Размер разрастающейся фигуры рассчитан по диагонали окна. Есть отдельные стартовая анимация и движение изображений при прокрутке.

Это полезный образец согласованного перехода нескольких объектов. Для Потока предлагается собственная короткая последовательность с карточкой; исходный код, изображения, шрифт и фирменные формы Obys переносить не планируется. На узком окне у Format показывается сообщение о desktop-опыте; это ограничение референса, которое Потоку не подходит.

### ModernLoop: что брать из подачи

На Scheduling Queues видны фрагменты карточек вокруг центрального сообщения, затем сцены с крупными изображениями рабочего интерфейса. Ближе к нашей задаче именно масштабирование полезного фрагмента. Бизнес-категории, отзывы, логотипы клиентов и обещания эффективности этого сервиса не относятся к Потоку. Копировать их или изобретать аналогичные доказательства нельзя.

### Chronicle: границы референса

На текущем сайте увидены крупный редактор презентации и выбор сценариев. Это современная версия; эффектам из конкурсной версии 2023 года не приписывается автоматическое наличие на ней. В каталогах Awwwards есть отдельные подборки микровзаимодействий и виджетов. Удобно заимствовать принцип «один выбор — понятная смена содержимого», сохраняя наши сущности.

## Перевод приёмов на наш продукт

Для совместного отбора каждому приёму присвоен ID:

| ID | Приём | Откуда идея | Что увидит человек | Приоритет предложения |
| --- | --- | --- | --- | --- |
| P1 | Изменение геометрии одной сцены | Format | Карточка появляется при скролле и занимает место в трёх днях | Главный кандидат |
| P2 | Крупный рабочий фрагмент | ModernLoop | В календаре можно только переносить; полный редактор находится отдельно | Основа композиции |
| P3 | Переключение сценария в одной области | Chronicle | «Занятие / Пара / Личное» меняет поля и вид одной карточки | Главный кандидат |
| P4 | След от исходного положения | Собственное поведение Потока | После переноса остаётся исходное место; возврат отменяет перенос | Сохраняем функционально |
| P5 | Связь источника и двух результатов | Наше наследование ссылок + подача возможностей у ModernLoop | Изменение общей ссылки отражается в двух событиях | Кандидат второй половины |
| P6 | Физическое табло с буквами | Уже выбранный владельцем приём Aceternity; Resend — дополнительный референс тактильности | Человек вводит короткую фразу, буквы перекидываются | Опциональный финал |
| P7 | Слабое взаимодействие фона с указателем | Уже исследованный Threads из React Bits | Фон реагирует на движение за пределами текста | Решить после P1; отдельная постоянная сцена может оказаться лишней |

Эта таблица — предложения. Одновременное включение всех семи эффектов не является планом.

## Исходная проверка текущего лендинга

Штатный `lint.mjs` Taste Skill запущен для Landing.jsx и двух файлов оформления лендинга. Сырой результат: **22 FAIL, 11 WARN**. Основные группы — градиенты, тонкие линии и тени. Файл результата сохранён.

Это проверка исходников, не оценка Awwwards и не число найденных пользовательских ошибок. Часть совпадений относится к настоящим формам и фрагментам интерфейса, для которых у навыка есть исключения; каждое совпадение нужно классифицировать. Декоративные совпадения не следует скрывать автоматическими ignore-комментариями. Полный браузерный аудит текущей страницы в этой фазе не проводился.
