# Две сборки, один интерфейс

## Открытый potok
Основное место разработки. Экспортирует исходники `@potok/core`: App, общие компоненты, hooks, модели и стили. `src/Site.jsx` открывает локальное личное расписание. `src-tauri` — начальная системная оболочка, не копия интерфейса. Сборка для браузера остаётся доступна для разработки и проверок; самостоятельный публичный сайт здесь не публикуется.

## Закрытый potok-cloud
Содержит лендинг, веб-маршруты, настройки нашего Firebase, Hosting, функции напоминаний и автопубликацию. Общий код подключается как локальный пакет `file:vendor/potok`, не копируется в src. Версия фиксируется полным SHA в core-source.json. Для совместной локальной разработки vendor/potok может быть символьной ссылкой на этот checkout; скрипт обновления отказывается перезаписывать такую ссылку.

## Настройки и доверие
Открытый клиент получает Firebase-конфигурацию из VITE_FIREBASE_CONFIG или из настроек конкретной установки. Сборка с VITE_FIREBASE_CONFIG считается управляемой: пользователь не может поменять проект в форме. Идентификаторы Firebase, попавшие в браузерную сборку, публичны по определению; права обеспечивают правила, авторизация и IAM. Административные ключи не хранятся ни в одном git-репозитории.

Закрытый workflow периодически проверяет main открытого репозитория, проверяет и собирает точный SHA и публикует сайт. Новая версия записывается в core-source.json только после успешной публикации. При неудаче следующая проверка повторяет попытку. Это опрос GitHub по расписанию, не мгновенный webhook; доступ к закрытому репозиторию из открытого workflow не нужен. Ручной workflow_dispatch позволяет опубликовать конкретный SHA.

## Разработка и следующие этапы
Интерфейс проверяется в браузере. Для системных возможностей нужен desktop-запуск и платформенные инструменты Tauri. Текущая локальная база остаётся localStorage; SQLite, устойчивую офлайн-очередь, системный Google OAuth и установщики добавляем отдельными изменениями. Разделение не меняет формат расписания и существующие данные пользователей.
