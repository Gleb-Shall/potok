# Общие элементы интерфейса

`src/components/UI.jsx` содержит Button, Field, Select, Check, Colors, Modal, FormFooter и форматирование дат. Родные HTML-контролы сохраняют семантику и клавиатуру. `Icon.jsx` хранит один набор SVG.

## Панели
У `Modal` появился флаг `panel`: тот же native dialog, но с закреплённым заголовком и формой/содержимым с отдельной прокруткой. Остальные модальные окна не меняют размещение. `editor-ui.css` отвечает за этот вариант, высоту контролов, отступы, предпросмотр и поведение на телефоне. Footer формы остаётся доступным при прокрутке, кнопки сохранения и отмены сгруппированы.

## Меню
`ActionMenu.jsx` использует native popover, поэтому меню не обрезается `overflow:hidden` календарной карточки. Компонент задаёт положение в пределах экрана, поддержку стрелок/Home/End, Escape с возвратом фокуса и закрытие при выборе/клике снаружи. Разрушительные команды имеют семантический цвет. Меню не выполняет доменные операции — только вызывает переданные обработчики.

## Что переиспользовать
Новые формы используют общие Button/Field/Modal и существующие цвета, а не независимые классы на каждом экране. Дополнительные поля записей и шаблонов раскрываются через details/summary. Не заменять ссылки кнопкой всей карточки: ссылки событий должны открываться отдельно.

Проверки: `tests/ui.test.jsx`, `tests/links-history.test.jsx`, целевые тесты действий редактора. Систему дизайна и источники решений см. в `.interface-design/system.md` и `docs/design-research/UI_SKILLS_AND_EDITORS.md`.

## Выбор времени
`TimeInput.jsx` сохраняет обычный time input на компьютере. На телефоне открывает нативный Modal с двумя scroll-snap колонками (24 часа, 60 минут; шаг строки 44 px). Изменение подтверждается кнопкой «Готово»; отмена не меняет исходное поле. Колонки поддерживают клавиатуру. Dialog вынесен порталом из label/form; начальное положение задаётся после `Modal.onOpen`, когда scroll-контейнер уже видим. Используется в TimingFields, MoveEditor и EventReminder. `tests/time-wheel.test.jsx`.
