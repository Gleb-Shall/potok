# Доска задач

`TaskBoard.jsx` показывает очередь переноса из календаря, три колонки задач и архив. На телефоне видна одна колонка, её можно сменить вкладкой. Удержание стикера через `usePressDrag` открывает три зоны назначения, подсветка следует за пальцем. Отпускание вне зон отменяет перенос. На компьютере мышь использует нативное перетаскивание. Смена колонки и действия в меню используют один обработчик статуса.

`TaskEditor.jsx` создаёт и редактирует задачи на доске и в инспекторе события. Выбор по дате позволяет привязать задачу к событию за пределами текущей недели. Из инспектора можно также выбрать ближайшее будущее событие с той же записью в пределах 91 дня.

`lib/tasks.js` обновляет `tasks` в общем хранилище. У задачи один статус, признак архива и необязательный `eventId`. Для повторов это идентификатор конкретного экземпляра. Обычный перенос сохраняет идентификатор события. Если связанное событие недоступно, задача остаётся на доске и связь можно поменять в редакторе.
