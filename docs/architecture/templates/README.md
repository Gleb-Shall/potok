# Шаблоны событий

## Файлы
`TemplateBrowser.jsx` и `TemplateTile.jsx` показывают существующие типы, предпросмотр, копирование и архив. `TypeEditor.jsx` редактирует определение типа; сохранение проходит через `saveType` в `src/lib/events.js`.

## Что хранится
У типа есть название, основной заголовок, цвет, категория связанной записи, обязательность связи, разрешение места и массив полей. У поля есть устойчивый id, формат, подпись, обязательность, архивность и варианты. Старые флаги видимости остаются запасным вариантом для шаблонов без настроенной композиции.

## Редактор
Общие настройки сворачиваются отдельно. В списке дополнительных полей одновременно раскрыто одно поле. «Добавить поле» выбирает новую строку. Отдельный инструмент «Оформление карточки» использует настоящий `EventCard` с `preview`, без записи в хранилище до сохранения.

## Инварианты
Нельзя менять формат поля, в котором уже сохранены значения событий/серий. Переименование и скрытие сохраняют данные. Варианты select/multiselect редактируются отдельными значениями; старые выбранные варианты остаются доступны у событий. Проверки пустых названий и вариантов выполняются перед сохранением; невалидное поле раскрывается.

Отдельного глобального шаблона для записей сейчас нет: постоянные сведения каждой записи описываются `RecordFields`, см. [раздел записей](../records/README.md).
## Свой фон карточки
`src/lib/card-backgrounds.js` проверяет PNG (до 10 МБ и 20 Мп), уменьшает его до 1200×900 и 64 КиБ, перекодирует в WebP с сохранением прозрачности. В браузере остаётся только готовая маленькая картинка; bitmap и canvas освобождаются. Ошибка загрузки не заменяет предыдущий фон.

Шаблон хранит `cardBackgroundId` и `cardBackgroundStrength` (0–50%, по умолчанию 20%). Общий словарь `data.cardBackgrounds` хранит data URL один раз. Фоны синхронизируются и экспортируются вместе с расписанием без Firebase Storage. Одинаковые картинки повторно не сохраняются. Лимит словаря — 360 КиБ символов, дополнительно действует лимит всего облачного payload. Снимки истории сохраняют только id; замена/удаление фона шаблона не уничтожает фон подтверждённых событий. Неиспользуемые картинки удаляются при сохранении шаблона.

`CardStyleEditor` показывает загрузку, замену, удаление, яркость картинки и реальное превью. `EventCard` рисует декоративный слой без обработки указателя; перенос, ссылки и маркер состояния работают поверх него. Символ типа больше не выбирается и не отображается; старое поле `icon` в данных не мешает загрузке старых копий.

Проверки: `tests/card-backgrounds.test.jsx`, `tests/ui.test.jsx`, `tests/links-history.test.jsx`.

## Подписи ссылок
Поле формата url может иметь `linkLabel` — «Текст ссылки в карточке». Пустое значение использует название поля. В свёрнутом и развёрнутом EventCard ссылки выведены отдельными именованными действиями без повторного dt/URL; ссылки связанной записи используют название её поля. Адрес остаётся в href/title и редактируется в событии/записи. Общая ссылка скрывается, если событие задаёт свою ссылку для того же поля. `LinkedText` по-прежнему поддерживает `[подпись](https://адрес)` внутри обычного текста.

Стандартный шаблон «Личное» больше не добавляет текстовое поле `fields.location`: место выбирается отдельной кнопкой и хранится в `event.location`. Это изменение касается новых шаблонов и примеров; существующие определения и их значения сохраняются.


## Оформление карточки

В «Шаблонах» кнопка «Поля шаблона» открывает `TypeEditor`: названия, форматы, обязательность, варианты и связи. Кнопка «Оформление карточки» открывает `CardStyleEditor`: раскладки, подписи ссылок, цвет, непрозрачность фона, PNG и эффекты выделения.

`card-style.js` проверяет `type.cardStyle`: оттенок, непрозрачность, два переключателя эффектов и независимые списки `{id, slot}` для короткой, часовой, досочной и развёрнутой карточки. Поля связываются по устойчивому ID. Строка деталей, бейдж и подписанная ссылка не меняют значения и правила заполнения. Отсутствующая раскладка использует старые флаги видимости; скрытые и удалённые поля не возвращаются. Существующие связанные ссылки остаются рядом. Очень короткая карточка оставляет место названию и метке; полные значения доступны в деталях события.

На компьютере один клик выделяет одну карточку и показывает ручки растягивания, двойной клик или Enter открывает событие. На сенсорном экране обычный тап по-прежнему открывает событие. Значок места и ссылки — отдельные действия.

`SelectedCardMotion` лениво подключается только для выбранной карточки или при выделении в предпросмотре. Дым рисуется на ограниченном Canvas 2D, буквы смещаются через transform. Кадры заканчиваются после затухания. Эффекты приостанавливаются при перетаскивании, растягивании, открытии диалога, вне экрана и во вкладке в фоне. Экономный режим и системная настройка уменьшения движения отключают оба эффекта.
