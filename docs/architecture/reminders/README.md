# Напоминания

## О переносе

У события в статусе «Ждёт переноса» может быть одно напоминание. Кнопка «Напомнить» на доске или в журнале открывает `ReminderDialog.jsx`. Доступны «Завтра в 09:00» и выбор даты и времени. После назначения даты или смены статуса напоминание удаляется при сохранении расписания.

## Перед событием

`EventAlertEditor.jsx` настраивает название и точные дату и время. У каждого экземпляра события может быть несколько независимых напоминаний. При переносе, переходе в ожидание новой даты, завершении или удалении события проверка при сохранении удаляет его напоминания. Возврат события на прежнее время оставляет их отменёнными.

## Хранение и доставка

- `payload.reminders` хранит напоминания о переносах. `payload.eventAlerts` хранит напоминания перед событиями вместе с идентификатором и исходным временем экземпляра.
- `src/lib/reminders.js` проверяет ввод в московском времени и сохраняет момент в UTC. При редактировании появляется новый идентификатор доставки.
- `src/lib/events.js` сверяет напоминания перед событием с расписанием при нормализации. `src/lib/reminder-model.js` определяет формат, индекс следующей отправки и текст для общего отправителя.
- `src/App.jsx` показывает наступившие напоминания внутри открытого приложения, обновляя время раз в минуту и при возврате во вкладку. Нажатие открывает нужное событие.
- `src/adapters/firebase/notifications.js` запрашивает разрешение по нажатию, регистрирует браузер и отзывает его подписку при выходе. `public/firebase-messaging-sw.js` отображает системное уведомление и обрабатывает переход к событию.

Фоновая доставка доступна в Firebase-сборке после включения push и разрешения на устройстве. Облачный индекс `nextReminderAt` добавляется при включённом push. Напоминание перед событием истекает в момент его начала. Инструкция по публикации функции, правил и индексов находится в документации облачной сборки.

Сборка для iPhone подключает AlarmKit через адаптер `nativeAlarms`. Поле `alarmDevice` указывает устройство, на котором должен прозвучать будильник. Такие будильники исключены из веб-доставки. `useDeviceAlarms.js` сверяет их с расписанием после загрузки актуальных данных и при возвращении приложения на экран.

Проверки модели и интерфейса находятся в `tests/reminders.test.js`, `tests/event-reminder.test.jsx` и `tests/rules/workspace.rules.test.js`.
