# Карты событий

`MapCanvas.jsx` лениво выбирает OpenFreeMap/MapLibre или необязательный Apple MapKit JS. Он используется картой раздела, мини-картой события и выбором места. Каждая реализация удаляет карту, markers, ResizeObserver и собственные обработчики при размонтировании.

`useMapTheme.js` следит только за `data-theme` рабочей области через один MutationObserver на открытую карту и отключает его при закрытии. Тема приложения используется также для загрузки, ошибок и выбора провайдера. Светлый лендинг не меняет сохранённое предпочтение рабочей области.

MapLibre выбирает Liberty для светлой темы и OpenFreeMap Dark для тёмной. `VITE_MAP_STYLE_URL` и `VITE_MAP_DARK_STYLE_URL` позволяют переопределить стили. При изменении темы вызывается `setStyle` существующего экземпляра: камера, markers и GL-контекст не создаются повторно. Apple Maps получает `colorScheme: light/dark` при создании и обновляет это свойство при переключении темы; SDK остаётся необязательным и требует собственного браузерного токена с подходящими доменами.

Проверки: `tests/map-theme.test.jsx`, `tests/apple-maps.test.jsx`. Разворачивание мини-карты без повторного создания проверяет `tests/week-calendar.test.jsx`.
