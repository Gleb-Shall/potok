# Лендинг и пространственные сцены

`src/components/Landing.jsx` собирает публичную главную. Компоненты `landing/ProductDemo.jsx`, `EventStudio.jsx`, `RecordNetwork.jsx` показывают перенос, изменение карточки и общие сведения на вымышленных данных. Эти данные не записываются в личный аккаунт.

## Пространственная часть
`landing/world/world-engine.js` создаёт Three.js-сцену, измеряет настоящие DOM-панели и передаёт им управление по окончании перехода. `ribbon-flight.js` задаёт траектории и деформацию лент. `story-time.js` хранит расстояния прокрутки и интервалы остановок. `dom-surface.js` рисует текстуры по реальным размерам и типографике DOM. `render-quality.js` выбирает плотность рендера.

На телефоне вход календаря упрощён: настоящие панели дней появляются с боков, без объёмного наложения. Остальные переходы используют компактные траектории и отдельные конечные прямоугольники. Раскрытая сцена не должна блокировать настоящие элементы управления после посадки.

`landing-spatial.css` определяет композицию главной; старые landing CSS остаются нижними слоями системы. Нельзя добавлять постоянный render-loop ради неактивной сцены. Уважать reduced motion, уход страницы в фон и потерю WebGL-контекста.
Проверки: `tests/product-demo.test.jsx`, `tests/ribbon-flight.test.js`, `tests/flow-playground.test.jsx`.
