# История и переносы

`HistoryView.jsx` проецирует `historyEvents` за выбранный месяц, фильтрует статус и запрос. Список показывает компактные строки вместо развёрнутых календарных карточек: время, название, контекст, подтверждение проведения. Нажатие передаёт в инспектор сам исторический occurrence, а отметка проведения — тот же объект и новый статус. Это сохраняет правильную обработку повторов. Оранжевое закрашивание остаётся в календаре, в истории оно не используется.

`TransfersView.jsx` показывает очередь без даты и изменённые события с исходным/новым временем. Сортировка использует последнюю запись history; открытие передаёт id сохранённого события в App. Пустые состояния не окружены внешней карточкой.

Оба раздела используют `EventListRow`, а ожидание — `PendingEventCard`. Оформление принадлежит `activity-views.css`, цвета — семантическим переменным `theme/colors.css`. Ссылки формирует общий `lib/links.js:eventLinks`: собственная ссылка события имеет приоритет над общей ссылкой записи с тем же адресом или названием поля. Отображаемые поля выбирает вызывающий компонент.

Проверки: `tests/activity-views.test.jsx`, `tests/links-history.test.jsx`. Для проверки заполненных экранов в браузере — `/tests/ui/` на локальном сервере.
