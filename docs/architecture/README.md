# Архитектура «Потока»

Общее приложение использует Preact и Vite. `src/main.jsx` запускает локальное пространство, а `src/App.jsx` связывает разделы и общий поток сохранения. Веб-сайт с Firebase находится в отдельном закрытом репозитории.
