# Записи и постоянные сведения

## Файлы
`RecordsDirectory.jsx` — каталог и фильтры. `RecordEditor.jsx` — предметы, люди, проекты и свои категории. `StudentEditor.jsx` — совместимый редактор ученика с контактом и направлением. `RecordFields.jsx` — дополнительные сведения; `RecordSummaryPreview.jsx` — живое представление записи.

## Поток
Редакторы держат локальный черновик. `saveRecord`/`saveStudent` проверяют поля и возвращают новую версию данных, затем `App.commit` сохраняет её через рабочее пространство. Открытие/предпросмотр не сохраняют изменения.

Постоянные сведения принадлежат записи, дата и детали отдельной встречи — событию. Для ссылок можно включить отображение в связанных событиях. Тип `url` и поддержка именованных ссылок проходят через `src/lib/links.js` и `LinkedValue.jsx`; исполняемые протоколы не допускаются.

Записи одной категории могут использовать одинаковое поле. «Добавить поле из категории» переносит определение и ID, значение заполняется отдельно для каждой записи. Поля поддерживают текст, ссылки и числа. Старые индивидуальные поля сохраняют свои ID. Стоимость урока задаётся в событии, а сохранённый ранее тариф ученика остаётся в данных для совместимости.

## UI
У каждого дополнительного поля раскрываются название, формат, значение и настройки показа. Основные сведения остаются выше списка, заметки и цвет — в дополнительном разделе. Предпросмотр на телефоне свёрнут; опасные действия находятся в меню.

Удаление общей записи не должно уничтожать историю событий: операции в `events.js` отсоединяют связь/сохраняют снимок по выбранной области удаления. Не добавлять независимую логику удаления в UI.
Проверки: `tests/links-history.test.jsx`, `tests/ui.test.jsx`.

## Шаблоны записей

`RecordTemplateBrowser.jsx` показывает шаблоны записей в общем редакторе шаблонов. `RecordTypeEditor.jsx` редактирует определения полей выбранного шаблона. Они хранятся в `recordTypes` рабочего пространства. Типом служит текущий `kind`, а значения остаются в конкретной записи по стабильному ID поля. Дополнительное поле отдельной записи можно объявить на уровне типа с сохранением его ID. Убирать поле из типа можно, пока на него не ссылается шаблон события. Уже заполненные сведения остаются в записях.

Шаблон записи удаляется из общего редактора, если от него не зависят записи и шаблоны событий. `deletedRecordKinds` исключает удалённые встроенные шаблоны из списка. Каталог записей ищет по имени, контактам и полям и фильтрует по шаблону и активным повторам.
