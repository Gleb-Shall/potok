# Записи и постоянные сведения

## Файлы
`RecordsDirectory.jsx` — каталог и фильтры. `RecordEditor.jsx` — предметы, люди, проекты и свои категории. `StudentEditor.jsx` — совместимый редактор ученика со стоимостью и направлением. `RecordFields.jsx` — дополнительные сведения; `RecordSummaryPreview.jsx` — живое представление записи.

## Поток
Редакторы держат локальный черновик. `saveRecord`/`saveStudent` проверяют поля и возвращают новую версию данных, затем `App.commit` сохраняет её через рабочее пространство. Открытие/предпросмотр не сохраняют изменения.

Постоянные сведения принадлежат записи, дата и детали отдельной встречи — событию. Для ссылок можно включить отображение в связанных событиях. Тип `url` и поддержка именованных ссылок проходят через `src/lib/links.js` и `LinkedValue.jsx`; исполняемые протоколы не допускаются.

## UI
У каждого дополнительного поля раскрываются название, формат, значение и настройки показа. Основные сведения остаются выше списка, заметки и цвет — в дополнительном разделе. Предпросмотр на телефоне свёрнут; опасные действия находятся в меню.

Удаление общей записи не должно уничтожать историю событий: операции в `events.js` отсоединяют связь/сохраняют снимок по выбранной области удаления. Не добавлять независимую логику удаления в UI.
Проверки: `tests/links-history.test.jsx`, `tests/ui.test.jsx`.
