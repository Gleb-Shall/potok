# Пользовательское руководство

Руководство открывается из меню разделов и настроек. Из статистики ссылка ведёт прямо к её главе.

- `src/components/guide-content.js` содержит главы, пошаговые инструкции и привязки ключевых фраз к примерам.
- `src/components/GuideView.jsx` отображает оглавление, выбранную тему и переходы между темами.
- `src/components/GuideExamples.jsx` и отдельные компоненты примеров показывают перенос, связи записей, журнал, статистику и доску задач. Данные примеров живут внутри открытого упражнения. Кнопка «Сначала» сбрасывает упражнение.
- `src/guide.css` задаёт оформление статей и примеров.

Схемы хранения и интеграции описаны на [страницах соответствующих разделов](../README.md).

Проверки навигации и упражнений находятся в `tests/activity-views.test.jsx`.
