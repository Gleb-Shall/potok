# События и история

## Файлы
- `EventDetails.jsx` — панель просмотра, статус, основные действия и редкие команды в `ActionMenu`.
- `EventEditor.jsx` — значения события, связь с записью, повторения, место и дополнительные поля.
- `MoveEditor.jsx` — выбранная дата и новое время; расширенное редактирование сохраняет незавершённый ввод.
- `StopSeriesDialog.jsx`, `DeleteDialog.jsx` — явный выбор области изменения/удаления.
- `TimingFields.jsx` и `src/lib/timing.js` — согласование начала, конца и длительности.
- `HistoryView.jsx` и `src/lib/event-history.js` — прошедшие события и подтверждение проведения.

## Модель
`src/lib/events.js` сохраняет разовые события и расписания повторений. У проекции есть `seriesId` и `anchorDate`; разовый перенос хранится как исключение с историей. Связанные сведения берутся из записи, а исторические снимки сохраняют прежние значения после изменений/удалений источников.

Статусы: `planned`, `done`, `pending`, `cancelled`. Прошедшее время само по себе не переводит событие в `done`. UI меняет статус через `App.statusEvent`, затем `setEventStatus`. Завершение серии сохраняет прошлые экземпляры и прекращает будущие повторы.

## UI
Редактирование и перенос — основные кнопки. Статус — отдельное свойство. Завершение повторов, отмена и удаление находятся в меню. Само открытие панели/меню ничего не записывает.
Проверки: `tests/ui.test.jsx`, `tests/links-history.test.jsx`, тесты модели в `tests/*.test.js`.
