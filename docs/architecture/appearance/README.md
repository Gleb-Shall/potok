# Внешний вид

`AppearanceSettings.jsx` — раздел личного кабинета. `src/lib/appearance.js` хранит качество под ключом `potok:animation-quality` и сообщает об изменениях через `potok:appearance-change`; между вкладками используется storage event. Настройка индивидуальна для устройства.

Landing render quality and world-engine now belong to the private website. The shared appearance preference remains in core.

`src/lib/color-theme.js` хранит отдельную настройку `potok:color-theme`: light (по умолчанию), dark, system. Выбор сообщается через `potok:color-theme-change`, между вкладками — storage event. Если localStorage недоступен, выбор остаётся в памяти вкладки. Тема и качество анимаций не меняют друг друга.

`calendar-workspace.css` задаёт новую оболочку приложения, `editor-ui.css` — панели, меню и формы. Семантические переменные цвета берутся из существующей системы; отдельная палитра редактора не создаётся.
Проверки: `tests/appearance.test.jsx`, `tests/entry.test.jsx`.

`useWorkspaceTheme` вызывается в App до любого условного возврата, поэтому охватывает календарь, экран входа и диалоги-порталы. Layout effect выставляет `html[data-theme]`, `color-scheme`, theme-color и подписывается на системную тему. При уходе из App слушатели удаляются, возвращается светлое оформление без изменения сохранённого выбора. Поэтому общий код не привязан к маршрутам закрытого сайта, а лендинг остаётся светлым. ThemeProvider инициализирует качество и светлую оболочку загрузки; он не перезаписывает уже активную тему App.

`src/theme/colors.css` задаёт светлые и тёмные семантические токены: поверхности, текст, границы, поля, цветные события, сетка, текущее время, ошибки и ожидание. Новая тема использует data-theme, а не старый класс dark: старые правила не смешиваются с новой палитрой. Нативные дата/время следуют color-scheme. Изменение темы не создаёт цикл анимации и не перезагружает данные/карту.

Раздел внешнего вида расположен по центру общей поверхности окна. Нет повторяющегося крупного названия раздела и внешней рамки. В интерфейсе три выбора с небольшим образцом календаря, ниже — качество анимаций. Настройка остаётся локальной для устройства.

Проверки темы: `tests/appearance.test.jsx` — сохранение/повторное открытие, системная тема, storage, уход на лендинг/обратно и снятие слушателей.
